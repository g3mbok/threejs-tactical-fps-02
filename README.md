An original, offline tactical FPS set inside a storm-battered tidal terminal. Two crews contest the intake sites in short rounds, with a field armory, an objective device, and bots that flank, hold lanes, and react to contact.

## Run locally

```sh
node serve.ts
```

Open `http://localhost:8080` in a desktop browser with WebGL 2. Click **Deploy to terminal** to begin; the game uses no network requests or build step.

**Controls:** WASD move, mouse look, left click fire, right click focus, R reload, C crouch, Shift sprint, E plant/defuse, G throw a grenade, B open the armory, and Tab view the shift report.
